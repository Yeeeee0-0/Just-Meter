# Just Meter 0.1.3 · Preview

Just Meter 的首个公开预览版本，包含 macOS 独立应用与 VST3 插件。

### 本版包含

- 实时频谱、响度、峰值、历史曲线与立体声分析。
- 原生玻璃界面，支持浅色、深色、透明度和界面缩放。
- 可调整组件尺寸、排列和显示内容的自定义布局。
- 中文 / English 即时切换与语言偏好保存。
- 中英文统一安装器，可选择独立应用、VST3 或同时安装。
- 源码采用 MIT 许可证公开。

### 下载

安装文件：`Just-Meter-0.1.3-macOS-arm64-preview.pkg`

适用于 **Apple Silicon · macOS 26+**。安装前请退出 Just Meter 和 DAW。

此版本尚未完成正式签名与 Apple 公证，可能触发 macOS 安全提示或插件扫描拦截。

反馈问题时，请附上 macOS 版本、DAW 名称与版本，以及复现步骤。可通过仓库 Issues 或 yeehuang2002@163.com 联系。

Just Meter’s first public preview includes a standalone macOS app and a VST3 plug-in.

### Included

- Real-time spectrum, loudness, peak, history and stereo analysis.
- A native glass interface with light and dark appearance, transparency and interface scaling.
- Customizable widget sizes, arrangement and displayed data.
- Instant Chinese / English switching with saved language preferences.
- A bilingual installer with selectable app and VST3 components.
- Source code available under the MIT License.

### Download

Installer: `Just-Meter-0.1.3-macOS-arm64-preview.pkg`

Requires **Apple Silicon · macOS 26+**. Quit Just Meter and your DAW before installing.

This preview does not yet have Developer ID signing or Apple notarization. macOS may display security warnings or block plug-in scanning.

For feedback, include your macOS version, DAW name and version, and steps to reproduce the issue. Use the repository’s Issues page or contact yeehuang2002@163.com.
